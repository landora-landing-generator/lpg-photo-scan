Поиск людей на сайтах

Находит фото людей на ваших сайтах и рисует им замену.

1 Ключ

Настройки — можно не трогать

Для поиска людей хватает самой дешёвой модели, которая понимает картинки, например google/gemini-2.5-flash-lite. Пустое поле — она и будет.

Изменения применятся после «Сохранить».

Модели рисования

Из этого списка выбирается модель в окне кадра и в «Нарисовать кадр». Список берётся из каталога сервиса при каждом запуске: новые рисующие модели появляются сами, снятые с сервиса — уходят. Лишние уберите крестиком — они не вернутся. Модель, которой нет в списке, впишите так, как она названа в каталоге, — приложение проверит, что она рисует, и только тогда добавит.

      Описание для нейросети

      Пусто — нейросеть опишет кадр сама. Можно написать своё, например «мастер чинит кофемашину».

      Справка

      Как работать

      1. Выберите сервис, вставьте ключ → «Сохранить».
      2. Загрузите файл с сайтами (Excel .xlsx и .xls, .ods, .csv, .txt) → «Проверить сайты». Домены найдутся в любом столбце.
      3. Нажмите на сайт с отметкой «Есть лица» → на кадр → «Перерисовать».
      4. «Скачать на компьютер» → загрузите файл на сайт вместо старого.

      Итог

      • Есть лица — человек узнаваем. Менять первыми.
      • Части людей — руки, фигура со спины. Стоковое фото тоже повод для иска.
      • Проверить глазами — нейросеть не уверена, посмотрите сами.
      • Людей нет — ничего делать не нужно.
      • Сайт не открылся — причина в строке.

      Полезно знать

      • Новый кадр — того же размера, что старый, уже сжат для сайта.
      • Значок ↗ у названия сайта открывает сайт в браузере; подпись «стр. …» под кадром — страницу, где этот кадр стоит. Так можно глазами проверить, что нашла нейросеть.
      • Галочки слева от сайтов — выбрать несколько и разом проверить, перерисовать кадры с людьми или скачать новые кадры. Галочка в шапке таблицы выбирает все видимые сайты.
      • Галочки на кадрах внутри сайта — перерисовать только выбранные. Перерисовка идёт по три кадра сразу, её можно остановить.
      • «Скачать новые кадры» кладёт рядом файл replacements.csv — что на что менять. Несколько сайтов — каждый в свою папку.
      • Модель рисования выбирается прямо в окне кадра. Список моделей обновляется из каталога сервиса при каждом запуске; убрать лишние или добавить свою — в «Ключ» → «Настройки».
      • Медленные модели (Seedream, Qwen и другие) рисуют до 5 минут — счётчик времени в кадре показывает, что работа идёт.
      • Сайты проверяются по несколько сразу; 100 сайтов — обычно 5–15 минут.
      • «Заново» в строке сайта проверяет только его. Можно нажимать и во время проверки — сайт встанет в очередь.
      • «Повторить сайты с ошибками» — ещё раз только те, что не открылись или где часть кадров не проверилась. Остальные не трогает.
      • Один и тот же кадр проверяется один раз — на других сайтах и при повторной проверке он не стоит денег.
      • Сайт больше 300 страниц читается по первым 300 — в строке будет пометка.
      • Всё сохраняется само — приложение можно закрыть.

      Нарисовать кадр

      Перетащите свою картинку — получите новую по её образцу. Без картинки — опишите, что нужно.

      Система не даёт запустить?

      Mac: «Готово» → Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

      Windows: «Подробнее» → «Выполнить в любом случае».
