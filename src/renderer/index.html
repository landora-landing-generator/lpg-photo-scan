    Описание для нейросети

    Пусто — нейросеть опишет кадр сама. Можно написать своё, например «мастер чинит кофемашину».

    Справка

    Как работать

    1. Выберите сервис, вставьте ключ → «Сохранить».
    2. Загрузите файл с сайтами (Excel, CSV, TXT) → «Проверить сайты».
    3. Нажмите на сайт с отметкой «Есть люди» → на кадр → «Перерисовать».
    4. «Скачать на компьютер» → загрузите файл на сайт вместо старого.

    Итог

    • Есть люди — нужно заменить кадры.
    • Проверить глазами — нейросеть не уверена, посмотрите сами.
    • Людей нет — ничего делать не нужно.
    • Сайт не открылся — причина в строке.

    Полезно знать

    • Новый кадр — того же размера, что старый, уже сжат для сайта.
    • «Скачать новые кадры в папку» кладёт рядом файл replacements.csv — что на что менять.
    • Модель рисования меняется прямо в окне: выберите из списка или впишите свою.
    • Всё сохраняется само — приложение можно закрыть.

    Нарисовать кадр

    Перетащите свою картинку — получите новую по её образцу. Без картинки — опишите, что нужно.

    Система не даёт запустить?

    Mac: «Готово» → Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

    Windows: «Подробнее» → «Выполнить в любом случае».
