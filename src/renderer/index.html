Поиск людей на сайтах

Вставьте список сайтов — приложение откроет каждый и покажет, где есть фотографии людей.

1 Ключ для распознавания

Ключ нужен, чтобы нейросеть смотрела картинки. Выберите, чей у вас ключ, и вставьте его. Проверка пойдёт через выбранный сервис.

2 Список сайтов

Вставьте домены — по одному в строке или столбцом из Excel. Лишнее (https://, www, адреса страниц, повторы) приложение уберёт само.

    Справка

    Что делает приложение

    Открывает каждый сайт из списка, как обычный браузер: главную и до 20 внутренних страниц. Собирает все картинки, отбрасывает мелочь (иконки, логотипы) и показывает каждую нейросети с вопросом «есть ли на фотографии человек». Сайты не меняются — приложение только смотрит.

    Что значит итог

    • Есть люди — хотя бы на одной фотографии есть человек. Нажмите на строку — увидите эти кадры.
    • Проверить глазами — людей не нашлось, но часть кадров нейросеть не разобрала. Посмотрите их сами.
    • Людей нет — все кадры проверены, людей на них нет.
    • Сайт не открылся — причина написана в строке: домен не продлён, сервер не отвечает и т. п.

    Приложение отвечает только на вопрос «есть ли человек». Стоковое это фото или своё — оно не знает.

    Кнопки

    • Проверить сайты — проверяет сайты списка, которые ещё не проверены. Можно дописать новые домены и нажать снова.
    • Остановить — прерывает проверку. Готовые сайты сохраняются; недоделанные проверятся при следующем нажатии.
    • Проверить заново — проверяет весь список ещё раз, даже уже проверенные сайты.
    • Очистить — стирает сохранённые результаты. Список доменов остаётся.
    • Сохранить в Excel — файл с двумя листами: сайты с итогом и список кадров с людьми со ссылками.

    Результаты сохраняются сами: приложение можно закрыть и открыть позже.

    Если система не даёт запустить приложение

    Mac: откройте приложение двойным кликом, в окне «Apple не может проверить…» нажмите «Готово». Затем: Системные настройки → Конфиденциальность и безопасность → внизу «Всё равно открыть» → пароль Mac.

    Windows: в синем окне «Система Windows защитила ваш компьютер» нажмите «Подробнее» → «Выполнить в любом случае».
