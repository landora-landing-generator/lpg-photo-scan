Поиск людей на сайтах

Вставляете список доменов — приложение показывает, на каких сайтах есть фотографии людей.
Приложение внутреннее и не подписано у Apple и Microsoft (подпись платная). Поэтому при первом запуске система предупредит, что не знает его. Это ожидаемо — ниже написано, что нажать. Делается один раз.

Установка на Mac

Какой у вас Mac: меню → «Об этом Mac». Если в строке «Чип» написано Apple M1, M2, M3, M4 и т. п. — первая кнопка. Если «Процессор Intel» — вторая.

Скачать для Mac с чипом Apple Скачать для Mac с Intel
  1. Откройте скачанный файл lpg-photo-scan-mac-….dmg.
  2. В открывшемся окне перетащите значок приложения на папку «Программы».
  3. Откройте Программы и запустите LPG Photo Scan двойным кликом.
  4. Появится окно «Apple не может проверить, что приложение не содержит вредоносного ПО». Нажмите «Готово» (не «Переместить в корзину»).
  5. Откройте меню → Системные настройки → Конфиденциальность и безопасность. Прокрутите вниз до раздела «Безопасность».
  6. Там будет строка «Использование LPG Photo Scan заблокировано…». Нажмите «Всё равно открыть» и введите пароль от Mac.
  7. Приложение откроется. Дальше оно запускается обычным двойным кликом, без этих шагов.
Кнопки «Всё равно открыть» нет

Она появляется только после попытки запуска и исчезает примерно через час. Запустите приложение ещё раз (шаг 3), нажмите «Готово» и сразу откройте настройки.

Правый клик → «Открыть», как раньше, на macOS 15 Sequoia и macOS 26 Tahoe больше не работает — только через настройки.

Установка на Windows

Скачать для Windows
  1. Браузер может сказать, что файл скачивают редко. В Edge: «…» рядом с файлом → «Сохранить» → «Показать больше» → «Всё равно сохранить». В Chrome: «Сохранить» / «Всё равно скачать».
  2. Запустите скачанный lpg-photo-scan-win-x64.exe.
  3. Появится синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».
  4. Установка пройдёт сама, на рабочем столе появится значок LPG Photo Scan.
Windows пишет «Интеллектуальное управление приложениями заблокировало…» и кнопки «всё равно» нет

Это защита Smart App Control — она бывает включена на компьютерах с недавно установленной Windows 11 и не пропускает неподписанные программы совсем.

  1. Пуск → Безопасность Windows.
  2. Управление приложениями/браузером → Параметры интеллектуального управления приложениями.
  3. Выберите «Выкл.» и запустите установщик снова.

На свежих версиях Windows 11 её можно потом включить обратно в том же месте. Если переключатель серый и не нажимается — напишите тому, кто прислал вам ссылку.

Что понадобится

Ключ одного из сервисов — OpenRouter, polza.ai или OpenAI: им приложение распознаёт людей на картинках. Проверка 100 сайтов стоит от 1–3 долларов (100–300 ₽ на polza.ai). Ключ вставляется в приложении, оно же подскажет, если с ним что-то не так.

Новая версия

Когда она выйдет, приложение само покажет плашку со ссылкой сюда. Скачайте и установите поверх — результаты проверок сохранятся.
